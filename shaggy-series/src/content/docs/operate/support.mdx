Open the **Support** section from the console sidebar. It has two tabs: **Overview** and
**Feedback**.

## Get help

- **Email:** [support@zekt.dev](mailto:support@zekt.dev). Support is best effort, during
  09:00–18:00 CET, Monday to Friday. There's no guaranteed response time.
- **FAQ:** links to these docs. Start with [Troubleshooting](/zekt-docs/reference/troubleshooting/).
- **Help assistant:** an automated assistant with ready-made answers. It doesn't connect you to a
  person; for that, use email.

## Send feedback

**Support → Feedback** has a form:

| Field | Options |
| --- | --- |
| **Type** | Bug, Feature Request, Question or Documentation. |
| **Component** | Public Website, Management Console, Zekt GitHub Action, Backend/API or Data Model. |
| **Title** | Up to 100 characters. |
| **Description** | Markdown. |

An option, on by default, adds an identifier and a timestamp to your report. **Submitted Issues**
lists what you've sent, with each item's state and comment count.

<Aside type="caution" title="Feedback is public">
	Submitting feedback creates a **public GitHub issue** in Zekt's feedback repository, posted under
	**your GitHub account**. Don't include secrets, payloads or private details. Use
	[support@zekt.dev](mailto:support@zekt.dev) for anything private.
</Aside>
