## Ownership

- Your Zekt account is created the first time you sign in with GitHub. That GitHub login is the
  **account owner**.
- An account's identity never changes. To transfer an account to another person, contact
  [Zekt support](mailto:support@zekt.dev).
- To share the account with colleagues, add them as [members](/zekt-docs/operate/members/).

## Accounts and GitHub organizations

A GitHub organization is only a scope where repositories live. One account can hold repositories
under several organizations and personal GitHub accounts. Several accounts can have repositories
under the same organization, and each account is billed separately.

**Profile → Your GitHub Organizations** lists the organizations *you* belong to on GitHub. The list is
about you, not the account. If an organization enforces SAML single sign-on, GitHub may hide it until
you choose **Authorize SSO**.

## One account per repository

A repository can be enabled by only one Zekt account at a time. If another account already holds
it, you'll see **Repository Already Enabled**. You have three options:

1. Ask the account that holds it to disable it.
2. Ask an admin of the GitHub organization to remove the repository from the Zekt GitHub App
   installation. This releases it straight away, but it also stops all deliveries for that repository.
3. Email [Zekt support](mailto:support@zekt.dev).

## Delete your account

Only the account owner can delete an account. Zekt doesn't offer a data export or a grace period, so
make sure you have everything you need first.

<Steps>

1. Open the user menu and go to **Account Settings → Danger Zone → Delete Account**.
2. Type `DELETE` to confirm.
3. If the account has other owners, a second step lists them. Type `DELETE <account id>` to confirm.
4. If the account has a payment method, Zekt first sends a **final invoice**: any month not yet
   invoiced, plus the current month pro-rated to the day. Deletion goes ahead once it's paid.
   If payment fails, Zekt retries for up to 7 days and then deletes the account anyway. If you
   delete during the [free trial](/zekt-docs/billing/how-billing-works/#free-trial), there's no
   charge.

</Steps>

If deletion is refused, the dialog explains why.

### What happens after deletion

- The providers and consumers your account was connected to each get a notice that the connection
  has ended.
- Zekt keeps a small amount of data:
  - billing records for invoiced months, for 12 months;
  - ratings and complaints other accounts made about your services;
  - the scores of ratings you gave, without their text;
  - complaints you filed, without your email address.
- Everything else is deleted. For the legal terms, see the
  [Terms of Service](https://www.zekt.dev/terms-of-service.html).

<Aside type="caution" title="Uninstall the GitHub App yourself">
	Deleting your Zekt account doesn't remove the Zekt GitHub App from your repositories. Uninstall it
	in your GitHub settings.
</Aside>
